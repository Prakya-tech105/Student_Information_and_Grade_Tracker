# Student Information and Grade Tracker

A simple Java console application to manage student details, subject marks,
CGPA calculation, report cards and student rankings.

## Student details stored
- Name
- USN
- Date of birth
- Phone number
- Email
- Department

## Features
- Add student details
- Display all student records
- Record and update subject marks
- Validate marks between 0 and 100
- Calculate CGPA
- Generate student report cards
- Display rank list based on CGPA

## Java concepts used
- Abstraction, encapsulation, inheritance and polymorphism
- Custom exception handling
- HashMap and ArrayList
- Insertion sort

## Requirements
- Java JDK installed
- Windows Command Prompt (CMD) or terminal

## Run using Windows CMD

Open CMD in this project folder.

Compile:
`javac *.java`

Run:
`java main`
